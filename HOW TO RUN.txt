==========================
3. BACKEND SETUP
==========================

Step 1: Create virtual environment

cd backend
python -m venv venv

Windows:
venv\Scripts\activate

Linux/Mac:
source venv/bin/activate


Step 2: Install dependencies

pip install fastapi uvicorn pandas numpy scikit-learn xgboost lightgbm catboost tensorflow shap joblib requests python-multipart


Step 3: Environment variables

Create .env file inside backend:

DATA_GOV_API_KEY=YOUR_KEY
WEATHER_API_KEY=YOUR_KEY


==========================
4. TRAIN MODELS (ONLY FIRST TIME)
==========================

If models do not exist:

python model_engine.py

This will:
- Load historical AQI dataset
- Perform preprocessing
- Train XGBoost
- Train LSTM
- Compute ensemble weights
- Save models inside /models/


==========================
5. RUN BACKEND SERVER
==========================

uvicorn main:app --host 0.0.0.0 --port 8000 --reload

Server will run at:

http://localhost:8000


Test endpoint:

Open browser:
http://localhost:8000/docs

Use Swagger UI to test /predict

==========================
8. CONNECT FRONTEND TO BACKEND
==========================

Inside script.js:

Change API URL:

const API_URL = "http://localhost:8000/predict";

Ensure CORS enabled in FastAPI:

In main.py:

from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

==========================
12. DEPLOYMENT (PRODUCTION)
==========================

Backend Deployment:

Option A: Render
- Connect GitHub
- Add Start Command:
  uvicorn main:app --host 0.0.0.0 --port 10000

Option B: AWS EC2
- Install Python
- Clone repo
- Install dependencies
- Use:
  sudo systemctl create service for uvicorn

Option C: Docker

Create Dockerfile:

FROM python:3.10
WORKDIR /app
COPY . .
RUN pip install -r requirements.txt
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

Build:

docker build -t vayudrishti .

Run:

docker run -p 8000:8000 vayudrishti


==========================
13. COMMON ERRORS
==========================

CORS error:
→ Enable CORSMiddleware

Model not found:
→ Run model_engine.py first

Port already in use:
→ Change port

SHAP slow:
→ Precompute expected values

LSTM slow:
→ Use CPU optimized TF build
